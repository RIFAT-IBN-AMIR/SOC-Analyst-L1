# 🇬🇧 English Version

## 1. Learning Objectives

The objective of this session was to understand the fundamentals of Security Operations Center (SOC), SOC Analyst responsibilities, and the basic IP investigation process.

## 2. Theoretical Learning

### 2.1 What is SOC?

A Security Operations Center (SOC) is a centralized security team responsible for monitoring, detecting, analyzing, and responding to cybersecurity threats to protect an organization's IT infrastructure, systems, and data.

### 2.2 SOC Analyst Workflow

Learned the basic workflow of SOC operations:

1. Security Monitoring
2. Alert Detection
3. Alert Triage
4. Investigation and Analysis
5. Incident Response
6. Documentation and Reporting

### 2.3 SOC Analyst Roles and Responsibilities

Studied the responsibilities of different SOC positions.

**Role and Main Responsibilities
1.SOC L1 Analyst - Initial alert monitoring, triage, and basic investigation 
2.SOC L2 Analyst - Detailed investigation, incident analysis, and response 
3.SOC L3 Analyst - Advanced threat hunting and complex incident investigation 
4.SOC Manager - Team management and overall SOC operations 

## 3. Hands-on Practice

### Lab 01: Basic IP Investigation Using VirusTotal

**Tool:** VirusTotal  
**Activity:** Sample IP address investigation

#### Activities Performed

- Selected a sample IP address.
- Searched for the IP address using VirusTotal.
- Explored the IP investigation interface.
- Reviewed detection information.
- Examined IP reputation.
- Explored related information and network details.

## 4. Investigation Findings

Explored the following investigation areas:

- Detection Overview
- IP Reputation
- Geolocation
- ASN (Autonomous System Number)
- ISP (Internet Service Provider)
- Related Information

**Key Observation:**

VirusTotal provides threat intelligence information that can help security analysts investigate suspicious IP addresses and understand their reputation and associated network information.

## 5. Challenges and Knowledge Gaps

- Understanding IP reputation and detection results.
- Understanding the responsibilities of different SOC Analyst levels.
- Learning how to interpret information provided by threat intelligence tools.

## 6. Key Learning Outcomes

- Understood the basic concept and purpose of SOC.
- Learned the fundamental SOC Analyst workflow.
- Understood the responsibilities of L1, L2, L3, and SOC Manager.
- Gained initial practical experience with IP investigation using VirusTotal.
- Learned the importance of threat intelligence in security operations.

## 7. Next Learning Goals

- Understand IOC (Indicator of Compromise).
- Learn Public IP and Private IP differences.
- Study TCP, UDP, and common network ports.
- Practice independent IP investigation.


# 🇯🇵 日本語版

## 1. 学習目標

SOCアナリストの基本的な仕組み、SOCアナリストの役割、およびIPアドレスの基本的な調査方法を理解することを目標としました。

## 2. 理論学習

### 2.1 SOCとは何か

SOCは、企業や組織のITインフラ、システム、データを守るために、サイバー脅威の監視、検知、分析、対応を行う専門チームです。

### 2.2 SOCアナリストの業務の流れ

SOCの基本的な業務の流れについて学びました。

1. セキュリティ監視
2. アラートの検知
3. アラートのトリアージ
4. 調査と分析
5. インシデント対応
6. 記録と報告

### 2.3 SOCアナリストの役割と責任

 **役割 と 主な業務**

1.SOC L1アナリスト - アラートの監視、初期確認、基本的な調査 
2.SOC L2アナリスト - 詳細な調査、インシデント分析、対応 
3.SOC L3アナリスト - 高度な脅威ハンティングと複雑なインシデント調査 
4.SOCマネージャー - チーム管理とSOC業務全体の管理

**使用ツール：** VirusTotal
